Business System & Architecture

🏢

1. Business System

DriveEasy – Smart Indian Car Rental System: An end-to-end multi-tier car rental marketplace connecting customers to 102+ verified vehicles across India with automated road distance calculation, transparent pricing with 5% GST, and self-drive/driver options.

⚡

2. Technology Stack

Built strictly with Pure HTML5, CSS3, and Vanilla JavaScript (ES6+). Zero external libraries, zero frameworks (no React, no Node backend needed to run). 100% lightweight and portable.

👤

3. User Module

Customer Portal:

  • Customer Registration with 10-digit Indian phone format (^[6-9]\d{9}$)
  • Local Storage authentication (driveeasy_users, driveeasy_session)
  • Live Indian road distance calculator across 80+ cities
  • 102 real car inventory categorized by company (Tata, Mahindra, Maruti Suzuki, etc.)
  • Transparent billing formula & date conflict collision protection
  • Customer personal dashboard with trip history & cancellations
🛡️

4. Admin Module

Operations Command Centre:

  • Dedicated restricted administrative authentication (admin@driveeasy.in)
  • Fleet Inventory Management: Full CRUD (Add, Edit, Delete, Toggle Availability)
  • HTML5 Canvas Dynamic Vehicle Condition Doughnut Chart (real-time updates)
  • Centralized booking lifecycle management (Confirmed, Active, Completed, Cancelled)
  • Customer directory with aggregated spending analytics
📐

5. UI Layout (CSS Grid & Flexbox)

All UI templates utilize CSS Grid (e.g. grid-template-columns: repeat(auto-fill, minmax(320px, 1fr)) for cars catalog, portal cards, metrics) and Flexbox (for navigation, car specs, action bars, invoice summaries, and filter bars).

🔄

6. Redirection & Navigation

Module-wise redirection handled dynamically using JavaScript (showScreen('entry'), showScreen('main'), showScreen('customer'), showScreen('admin')) preserving state without page reloads.
